========================================================================
PANDUAN LENGKAP CARA PASANG SIAKAD MADRASAH DI HOSTING PLESK / CPANEL (MYSQL)
========================================================================

Aplikasi Si@Kad Madrasah ini sudah dikompilasi menjadi paket Siap Pakai (Static Build)
yang terhubung langsung ke Database MySQL/MariaDB bawaan hosting Anda!

Anda TIDAK PERLU menginstall Node.js, npm, atau menjalankan 'npm install' di hosting!

------------------------------------------------------------------------
1. CARA INSTALL FILE WEB DI HOSTING PLESK / CPANEL
------------------------------------------------------------------------
1. Login ke Panel Hosting Anda (Plesk Panel / cPanel / DirectAdmin).
2. Buka menu "File Manager".
3. Masuk ke folder root domain Anda:
   - Jika di Plesk: masuk ke folder `httpdocs`
   - Jika di cPanel: masuk ke folder `public_html`
4. Hapus file bawaan hosting jika ada (seperti index.html atau default.html bawaan).
5. Upload file `siakadmadrasah-plesk-ready.zip` ke dalam folder tersebut.
6. Klik kanan / pilih file zip tersebut, lalu pilih "Extract" / "Unpack".
7. Pastikan seluruh file terurai langsung di dalam folder `httpdocs` / `public_html`
   (termasuk file `.htaccess`, `api.php`, `db_config.php`, dan `config.js`).

------------------------------------------------------------------------
2. CARA MENGHUBUNGKAN DATABASE MYSQL / MARIADB HOSTING & MELIHAT PORT
------------------------------------------------------------------------
1. Di Panel Hosting (Plesk/cPanel), buka menu "Databases" -> "Add Database".
2. Buat database baru, contoh nama: `siakad_madrasah`.
3. Buat User Database & Password untuk database tersebut.
4. Buka menu "phpMyAdmin", pilih database `siakad_madrasah` yang baru dibuat.
5. Klik tab "Import", upload file `database-mysql.sql` (yang ada dalam zip ini) lalu klik "Kirim" / "Go".
6. LOKASI PORT MYSQL DI HOSTING PLESK / CPANEL:
   - Port standar MySQL / MariaDB pada semua server hosting (termasuk Plesk & cPanel) adalah **3306**.
   - Di Plesk: Anda dapat melihat Host & Port pada halaman "Databases" -> Informasi koneksi database (tercantum `localhost` atau IP server dan port `3306`).
   - Jika PHP berjalan di server yang sama dengan database (sebagian besar hosting Plesk), Anda cukup memakai Host: `localhost` dan Port: `3306`.
7. Buka File Manager hosting Anda, edit file `db_config.php` dan masukkan rincian database Anda:

   <?php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'nama_db_anda');
   define('DB_USER', 'user_db_anda');
   define('DB_PASS', 'password_db_anda');

8. Untuk Menguji Koneksi:
   - Masuk ke Admin Si@Kad -> menu **Konfigurasi API & Database MySQL**.
   - Masukkan Host, Port (3306), Database, Username, dan Password, lalu klik tombol **"Tes Koneksi MySQL"**.
9. Selesai! Aplikasi Si@Kad Madrasah kini terhubung ke MySQL hosting Anda sendiri.

------------------------------------------------------------------------
3. TIPS OPTIMASI SUPAYA AKSES DI HOSTING SANGAT CEPAT & TANGKAS
------------------------------------------------------------------------
- File `.htaccess` bawaan paket ini sudah dikonfigurasi dengan:
  * Gzip Compression (Mengecilkan ukuran file JS & CSS otomatis hingga 70%)
  * Browser Caching (Menyimpan asset di browser pengunjung agar saat buka halaman berikutnya instan)
  * SPA URL Rewrite (Supaya halaman /login, /admin, dll dapat diakses langsung tanpa error 404)
  * Keep-Alive & Security Headers

- Pengaturan di Plesk (Opsional untuk kecepatan maksimal):
  1. Buka Plesk -> "Apache & Nginx Settings".
  2. Centang "Smart static files processing".
  3. Centang "Serve static files directly by Nginx" (jika Nginx tersedia).
  4. Aktifkan HTTPS/SSL melalui menu "SSL/TLS Certificates" -> Let's Encrypt.
